# Проверка Map Teleport 0.3.0 — 31 октября 2026

## Итог

Изображение и слой обозначений реализованы и проверены. Сохранены отдельная точка переноса, выбор региона, колесо, drag, полосы прокрутки, адаптация размера окна и отмена. В рабочем моде нет новых вызовов создания/удаления игровых меток. Исправление индексного обхода TArray из 0.2.1 сохранено; физический алгоритм этим изменением не переписан.

Среда: Dune 1.5.3.0, WPS 2.1.1, UE4SS 3.0.1-1140-gf58e8f84, Windows Sandbox/vGPU, 16 ГБ, сеть выключена. После требования пользователя GUI управляется только wbox-mcp (`sandbox-id-api-v2`). Игра отображена read-only; используются отдельный runtime и копия Cloud. Изменения тестового сохранения не переносятся в основную игру.

## Переход и повтор старых координат

DeepDesert → HarkoVillage прошёл полностью: штатный маршрут, местное размещение, VerifyReleased/Cleanup/result=success. Персонаж находится на поверхности; здоровье сохранилось. HarkoVillage → HaggaBasin также завершился успешно.

Повторены XY из двух отчётов о вылетах 27.10. Z вычислялся заново стандартной проверкой размещения мода; допускается безопасное смещение рядом, поэтому это не побитовое воспроизведение прежней сессии.

Первую попытку прервал продолжающийся урон жары, затем персонаж тестовой копии погиб; это не вылет процесса. Один bCanBeDamaged=false не остановил расход жизненных ресурсов, поэтому для повторов включён AFK в отдельной гостевой копии уже установленного мода (удержание hydration/HeatExhaustion и защита). Проверки поверхности, капсулы, readiness штатного уровня и освобождения временных уровней не отключались. В успешных повторах с защитой не подтверждается поведение урона падения/жары: они проверяют загрузку, размещение, движение и отсутствие исходного access violation на этих запросах. Обычный переход/здоровье Harko проверены до включения защиты.

Дамп handoff показал реальную промежуточную причину ожидания: native source.loaded=true, requested lod=-1, но фактически ещё Art_LOD2. Мод дождался штатной геометрии либо безопасно вернул персонажа; проверка не была снята ради успеха теста. Причина первого старого post-movement access violation не объявляется полностью установленной. Пограничные случаи и все поверхности всех регионов этой проверкой не исчерпаны.

## Границы источников и ввода

Для мест нужен resolved discovery штатного overlay. До первого открытия M или если игра ещё не предоставила объект, часть обозначений недоступна; легенда явно сообщает об этом. Подтверждённые plain значения сохраняются только в пределах текущего world/pawn/map. Метки другого не загруженного мира не выдумываются. Полный экран фильтров, группировка и конус обзора native карты не копируются.

Короткое синтетическое Shift+F12 wbox не открывало окно: инструмент отправляет down/up одновременно, а runtime проверяет удержание на game thread. Для UI применён sandbox-only вход в production application.open; release main.lua не изменён этим входом и совпадает с принятой реализацией сочетания. Это не новая ручная приёмка клавиатуры. Fixture, защита, координатные команды, диагностика и копии сохранений в ZIP не входят.

Ранний generic debug PersonalMarker ID -1770310950 из host-диагностики предшествовал wbox. ServerClearDebugMarkers вызван, но исчезновение из клиентского SPS до закрытия той сессии не подтверждено; не заявляем его очистку доказанной. Sandbox использует более раннюю копию без него. Production слой меток не создаёт.

## Автоматические проверки и поставка

17 Lua-наборов и strict OpenSpec validate прошли. Включены проверки переноса native scalar settings, проекции, plain snapshots/цветов, discovery, удалённых данных, invalid XY, дубликатов, пяти категорий, UI lifecycle, wheel/drag и ресурсов.

Две независимые сборки ZIP дали SHA-256 2E3D43CFE7FDE011C5B2340195595D31F87C612AF0F1053052E616A71146F428. Все 23 файла source/extracted/installed/frozen совпали. Перед установкой 20 файлов прежнего 0.2.1 отдельно заархивированы, распакованы и сверены; ZIP бэкапа CA59785DA4ACF5C0CACE8D2AE4974D338BEBB210DE6C6A7BE08D3D2AAD839823. В профиле MapTeleport=true, Probe=false; собственный Probe дополнительно не исполняется без явного arm-файла, даже если старое окно WPS держит прежний флажок в памяти.

Временные Sandbox завершаются через wbox stop с проверкой ownership и remaining. Чистый запуск готового пакета и итоговая очистка фиксируются ниже после выполнения.

## Чистый запуск и завершение

Финальная сессия a2cfb0dcec5f4b7c9971feb06e5e6475 загрузила 0.3.0: все 23 guest-файла совпали с ZIP/source/installed, Starting Lua mod MapTeleport подтверждён. Probe, WboxMapFixture и update/recovery errors в журнале отсутствуют. Соседний AFK использовался в неизменённой версии и был активен в финальном кадре; это не проверка урона. Синтетическое Shift+F12 готового пакета не открыло окно, ограничение ввода wbox остаётся явно непроверенным; main.lua SHA-256 совпадает с принятой пользователем реализацией 0.2.0. После завершения собственная Sandbox остановлена штатным wbox stop: status=released, remaining=[], errors=[]. Другие Sandbox/пользовательские приложения не закрывались.
