# Интеграция регионов и карт

Проверки 2026-10-25 выполняются отдельно от установленного MapTeleport 0.1.3. WPS обновлён в прежнем каталоге до 2.1.1; UE4SS остаётся 3.0.1-1140-gf58e8f84 (SHA-256 94C2EBD3CA9F4C4212898D727DF5482937F586771C67502635EBD4367422052A). Новый интерфейс пока не поставлен как готовый пакет.

## Штатные проверки и путешествие

Каталог читается из CDT_MapsInfo, CartographyMapSettings и DuneGlobalDataCacheSubsystem. RequiredJourneyNodeName разрешается JourneyUtils.GetJourneyNodeByName: возвращается JourneyTreeNodeGuiData; GetCompletionCount(mnemonic) возвращает структуру CompletedCount/TotalCount. Нужен MnemonicRecallActorComponent из PlayerState с GetIsJourneyStateInitialized=true. RequiredPlayerFlagsQuery вычисляется штатными IsTagQueryEmpty/DoesContainerMatchTagQuery над флагами персонажа. Изменений прогресса нет.

В текущем снимке WreckOfHephaestus закрыт: ReturnToHBSAndWait ещё Revealed, завершение узла не подтверждено. CanTravelToDestination при этом находит направление. Поэтому этот метод проверяет существование маршрута и целевой mapId, но не заменяет сюжетные условия и окончательную проверку сервера игры. Таблица «доступности» не строится по одному этому bool или по статическому m_Visitable: у доступного Арракина m_Visitable=false.

Проверенная сигнатура:

```lua
local target = {}
api:CanTravelToDestination(pawn, FName(destinationName), target)
-- target.Name:ToString() == native mapId
api:RequestTravelByDestination(pc, FName(destinationName),
    nil, nil, 'MapTeleport confirmed destination', dialogType, -1)
```

Делегаты nil принимаются; пустая Lua-таблица вместо делегата отклоняется до запроса. Корректный ненулевой делегат требует `{Object=UObject, FunctionName=FName}` с соответствующей сигнатурой. RequestTravelByDestination возвращает nil, что не означает завершение путешествия.

ETravelDialogType: RequestDialog=0, QueueDialog=1, NoDialog=2. NoDialog убирает лишний вопрос подтверждения; штатные проверки не отключает. Окончательный отказ считывается из ClientShowTravelRequirementsFailedDialog(mapId, FailReason FText) или ClientShowTravelFailedDialog(FailureReason); штатный диалог отказа сохраняется. Эти hooks ещё требуют проверки на новой интеграции.

Подтверждён штатный маршрут Travel_To_Arrakeen, RequestDialog=0 с обычным подтверждением: Hagga Basin (230015.015, -265452.125, 41321.604) → Arrakeen (11495, -316, 51550.536), здоровье 174.932 до/после. Смена мира подтверждена по свежему pawn, worldPath и DuneMapId, а не по возврату API. Доказательства: probe-239-native-travel.txt, probe-240-arrival.txt. NoDialog и полный составной перенос ещё не квалифицированы этим опытом.

## Часы, прибытие и составная операция

GameplayStatics:GetAccurateRealTime(out, unused) помещает Seconds и PartialSeconds в первую таблицу (вторая остаётся пустой). Их сумма — часы без привязки к UWorld; GetRealTimeSeconds текущего мира непригоден для deadline через загрузку. Доказательство: probe-247-clock-levels.txt.

region_travel.lua отправляет один запрос; лимит путешествия 120 секунд. Правильный мир, свежий персонаж, владение управлением и безопасная опора должны непрерывно подтверждаться 3 секунды. После этого регион без точки заканчивается на штатном прибытии, регион с точкой автоматически начинает местный этап. Текущий регион пропускает travel. Окончательный снимок копируется по значениям; поздние подтверждения не создают ещё одну операцию.

Origin местного этапа создаётся после прибытия в новом мире. Отказ местного размещения после путешествия — частичный результат, а не полный успех. Нет возврата координатами в прежний мир. Тайм-аут не повторяет запрос и не применяет точку при позднем прибытии. Обычный отказ разрешает новое независимое действие; неудачное восстановление/очистка отключают дальнейшее движение. Девять тестов region_travel_test.lua проверяют эти переходы; это не заменяет игровую приёмку.

## Штатные карты и собственное окно

ShowroomFunctionLibrary:GetShowroom(pc, 1) возвращает CartographyMapShowroom. Штатная карта рисуется в отдельном мире и использует RT_MenuMap. Регистратор ресурсов AssetRegistryHelpers:GetAssetRegistry():GetAssetsByClass с TopLevelAssetPath FullscreenMapDataAsset возвращает девять метаданных карт. Возвращённый out-массив — обычная Lua-таблица RemoteUnrealParam; свойства TArray обходятся ForEach, не ipairs.

Собственный BP_MapLayer_Survival_1 после OnIsCurrentMapLayerChanged(true) создаёт штатные MapMeshes, MapAreas, Borders. Просмотр чужого региона не требует путешествия. Общего масштаба 1:100 нет: адаптер сопоставляет m_MapLayerMapBounds с m_MapWorldLevelData выбранной карты. Собственная камера направлена по -Z, yaw=-90: вправо +X, вниз +Y. Perspective/FOV берётся из m_ZoomSteps, zoom меняет угол обзора при неизменной высоте; pan смещает камеру и обратное преобразование согласованно. Перспективная проекция берёт штатную плоскость курсора W_FullscreenMap.m_CursorProjectionPlaneHeight (25000 в этой сборке), преобразованную через диапазоны scene/world Z. Соответствие видимых ориентиров до 5 м ещё требует отдельной игровой проверки.

Копии и камера живут внутри CartographyMapShowroom, на удалении от штатной сцены, с отдельным RT того же формата/gamma, что RT_MenuMap. Штатные actor, камера, RT_MenuMap, MPC и PersonalMarker не меняются. OnlyOwnerSee не используется: SceneCapture не подтвердил подходящего view owner. FogLayer-копии скрываются: они зависят от исследования текущего мира и иначе перекрывают рельеф другого региона. Ортографический захват городов давал почти чёрный слой; перспективный режим и рабочая дистанция штатной камеры подтвердили читаемый Харкo и Арракин (probe-369…373). При закрытии удаляются свои актёры с проверкой членства в их showroom-мире.

Полноэкранное окно собирается из UMG-контролов игры, с её Raleway-шрифтом, тёмными панелями, золотыми подписями и кнопками. Отдельный Enhanced Input owner не меняет общие ignore-счётчики. Выбор региона сразу показывает местную карту и начальную точку; одно окончательное подтверждение начинает операцию. Рядом «Отменить», Escape также отменяет весь выбор. Навигация не начинает движение. Замеры производительности не входят в требования пользователя.

Новый UI и карты пока проходят изолированную отладку; не объявлять их квалифицированными до проверки жизненного цикла, ввода, преобразования и полного маршрута.

Особенности установленного runtime: FLinearColor отражает красный канал как `r` (нижний регистр), остальные G/B/A — верхний. MakeColor возвращает Lua-таблицу с этими ключами. Передача собственного Button.WidgetStyle обратно в SetStyle приводит к завершению процесса; стиль задаётся по полям до построения Slate. Реальный OnClicked с Add/Remove и отдельным native UFunction мостом проверен мышью. Диагностический вызов delegate:Broadcast из уже выполняющегося Lua callback оказался непригоден: это вложенный вход в hooked Lua. В рабочем коде Broadcast нет; обычные UI-события только ставят намерение в очередь постоянного игрового callback.

## Актуальное уточнение интерфейса и размещения

Выбор региона сразу показывает его местную карту; промежуточные OpenRegion/RegionScreen и второе подтверждение отменены. Один Confirm принимает точку, без местной карты — штатный маршрут. Отмена закрывает весь выбор.

Приоритет у точного выбранного X/Y. Резервный поиск выполняется с расширением от выбранной точки, по 8 проверок за callback; свободная капсула, уклон, опора, зазор и общий срок остаются обязательными. Исследуется штатный поиск появления; наличие функции по имени ещё не доказывает, что она возвращает пригодное место без движения.

## Штатные функции появления и исходная точка окна

Read-only probe-284: Engine.World:FindTeleportSpot не является доступной reflected UFunction в установленной игре. Документация движка описывает поиск ближайшего незанятого объёма, но наличие C++ функции не подтверждает Lua-доступ. RespawnFunctionLibrary:FindNearestSpawnLocation возвращает StaticSpawnLocatorName зарегистрированного места, а не исправленную произвольную координату. DuneGameplayUtilities:AdjustEndLocationIfBlocked принимает начало/конец луча и канал, не размеры капсулы; сама по себе пригодность персонажа не подтверждает. TeleportTo(bIsATest=true) не используется как запрос: в прежней проверке он реально переместил персонажа (docs/game-api.md).

В native глобальном кеше TravelDestinations содержится Transform.Translation каждого маршрута. В region_catalog его X/Y выбираются по destinationName и точному worldPath, без UObject в результате. Это собственная точка по умолчанию на карте; её можно заменить кликом. Probe-288/289: для Travel_To_Arrakeen X=11495,Y=-316 совпали с фактическим прибытием probe-240. Нулевая/иная текущая позиция персонажа не подставляется вместо неизвестного маршрута. При отсутствии данных требуется ручной выбор с объяснением.

Дополнение к проверке пола: в компактном городе верхняя грань невидимого блокирующего объёма не равна игровому этажу. Probe-393…408 подтвердили ложный success на такой грани в Харкo и восстановление без потери здоровья. Compact-профиль использует ближайшую по X/Y штатную DuneWorldSettings.m_UnstuckLocations для начальной высоты физического луча. Эти Transform читаются только в текущем мире, без вызова Unstuck, изменения мира или сохранений. При отсутствии таких данных профиль отвергается. Проверки полной капсулы, нормали и поддержки остаются обязательными; многоуровневые точки в целом ещё требуют приёмки. Подробности — docs/playtest-2026-10-25.md.

## Контракт физического профиля

map_profiles хранит только значения: mapId, worldPath, surface layer, границы X/Y, диапазон луча и стратегию подготовки. HaggaBasin использует hagga-streamed с SOS-MinorErg; DeepDesert — desert-streamed со своей сеткой, без переноса имени SOS-MinorErg. Arrakeen/HarkoVillage — compact, без временных ландшафтных клонов. Compact collision bounds и штатные recovery-высоты разрешаются после прибытия; кеш действителен только для точного c.key текущего персонажа/экземпляра мира. Изображение карты не подтверждает физическую готовность. Неподтверждённый профиль отклоняется явно.

Локальный автомат получает независимый снимок явной точки. map_adapter.point проверяет mapId/layer/конечность/границы по текущему профилю и не читает PersonalMarker. Смена c.key отменяет работу до обращения к старой геометрии. Регрессии map_profiles_test/map_adapter_test/teleport_test покрывают несовпадающие миры, слои, карты, высоты, транспорт, смерть, смену персонажа, восстановление/выгрузку и исключения. Игровое покрытие всех профилей остаётся отдельной задачей 5.2.

Дополнение 23:17–23:29: desert-streamed различает все экземпляры одного biome asset по полному имени streaming object и его LevelTransform. Общая геометрическая сетка выводится из минимум двух текущих LandscapeStreamingProxy, затем bounds загруженной цели проверяются с допуском 1 см до движения. Несовпадение означает отказ, а не приблизительную геометрию. Результаты S1/S2 — docs/playtest-2026-10-25.md.

Escape дополнительно принимается RegisterKeyBind(Key.ESCAPE) в очередь главного 50-мс callback. Обработчик клавиши не обращается к UObject. Отмена имеет приоритет над одновременным открытием и не отменяет Executing. Прежний UI-опрос Escape остаётся дополнительным способом. Probe-460/461 подтвердил короткую клавишу, Idle/point=nil/widget=nil и отсутствие собственных input owners после закрытия. В unit tests проверены очередь и конкурирующий Open.


Адаптивная карта: map_canvas задаёт общую виртуальную геометрию квадратной карты в прямоугольном viewport. Штатные ScrollBox управляют двумя независимыми смещениями; собственный ScrollBox принимает колесо Slate через OnUserScrolled → SetScrollOffset с совпадающей float-сигнатурой. Hook ограничен полным именем собственного объекта, возвращает его offset к центру и ставит plain zoom-событие в очередь. Колесо над списком регионов остаётся штатной прокруткой. Ввод игры и чужие ScrollBox не меняются.

Для качества увеличения собственный SceneCapture снимает только видимую область с тем же центром/FOV и aspect ratio, который использует click picking. Один RT ограничен 1536 пикселями по длинной стороне и меняет пропорции через ResizeRenderTarget2D; увеличение не создаёт гигантский RT. Снимок обновляется при изменении вида, а не каждый frame без изменения.

Диагностическая ошибка 23:33: DeprojectSceneCaptureToWorld в этой сборке принимает SceneCapture2D actor, а не CaptureComponent2D. Неверный аргумент probe-466 вызвал access violation; такой функции в рабочем коде нет. Исправленный read-only probe проверяет IsA(SceneCapture2D). Probe-517 доказал округление native UV к целому пикселю; сравнение использует floor(UV*RTSize)/RTSize. Probe-518 проверил 60 лучей четырёх карт при zoom 1/4/16 и сдвиге: наибольшая ошибка для одного native pixel — 0.001205 м. Сравнение с дробным UV без округления даёт ошибку до размера пикселя и не доказывает ошибку выбора точки.

RT выбирается с чётными размерами до 1536, минимальным относительным расхождением aspect и максимальной площадью среди равных вариантов; результат кешируется по viewport. Колесо и drag обновляют существующие capture/scroll offsets без перестроения дерева UI. OnPressed собственного map Button начинает жест; IsPressed и координаты опрашиваются игровым callback. Порог 6 logical units отличает drag от дрожания клика; отпускание после drag не меняет назначение. Закрытие/смена revision/потеря pressed очищают жест, делегаты и hooks освобождаются только у собственных объектов.

Модальное окно использует UIOnlyEx; Tab/Shift+Tab только ставят plain-намерения в очередь main.lua, которая меняет native focus из 50-мс игрового callback. Enter использует штатную кнопку, Escape имеет приоритет над открытием/навигацией. При закрытии восстанавливается прежний input mode. Probe-524/528 подтвердили физическую навигацию, колесо и drag без движения персонажа.
