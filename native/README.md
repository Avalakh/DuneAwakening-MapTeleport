# Нативный мост MapTeleport

Статус: разработка; игровая телепортация не реализована и не квалифицирована.

Мост загружается из Lua через `package.loadlib(path, 'luaopen_mapteleport_native')`.
Он использует публичные заголовки LuaMadeSimple точного UE4SS commit
`f58e8f840243d60e29d46e9bb2fcc2919ef6f926`; закрытые Unreal-заголовки не требуются.
Import library создаётся из экспортов уже установленного Runtime. Его файлы
не заменяются. Загрузка функций моста разрешена только для DLL с SHA-256
`94C2EBD3CA9F4C4212898D727DF5482937F586771C67502635EBD4367422052A`.

Из корня проекта, PowerShell:

```powershell
./tools/prepare-native-sdk.ps1 -RuntimeDll '<папка WPS>/Runtime/ue4ss/UE4SS.dll'
cmd /c tools\build-native.cmd
cmd /c tools\test-native.cmd
```

Проверенная среда сборки: Visual Studio 2022 Community, MSVC 14.44.35207,
Windows SDK, x64, Release `/MD`, C++20. Пути скриптов пока соответствуют этой
установке. `sdk-lock.json` фиксирует URL и SHA-256 публичных заголовков UE4SS
и fmt 11.0.2. Заголовки, import library и результат сборки находятся в `work/`.

`MapTeleportNativeGeometry` вызывается только в игровом потоке. Полученный
`FGeometry` остаётся непрозрачным буфером и передаётся непосредственно
`GetLocalSize` и `LocalToAbsolute`. Перед вызовом проверяются отражённые размеры
параметров и смещения возвращаемых значений для текущей UE5.2.
Адреса объектов передаёт адаптер после `IsValid`; их нельзя хранить между мирами.

Ввод перехватывается через оконную процедуру собственного окна Unreal.
Адаптер должен явно разрешать ввод только над доступной частью открытой карты,
обновляя её прямоугольник и поколение мира. Данные устаревают через 250 мс.
Принятые WM_RBUTTONDOWN/UP поглощаются парой; обычный ввод передаётся исходной
процедуре. Влияние Raw Input и перекрывающих карту меню ещё требует игровой
проверки. Этот путь не преобразует `FEventReply` в Lua.

`MapTeleportNativeShutdown` отключает приём кликов и восстанавливает исходную
оконную процедуру, если текущая процедура всё ещё принадлежит моду. При чужом
последующем перехвате возвращает false и сохраняет цепочку. DLL закреплена до
выхода процесса, поскольку UE4SS хранит указатели зарегистрированных callbacks.
Снятие ввода и физическая выгрузка DLL — разные операции.

Автотест проверяет границы, модификаторы, фокус, устаревание и корректное снятие
перехвата на отдельном скрытом окне, включая сохранение чужой последующей
процедуры. Это не подтверждает поглощение маркера или геометрию внутри Dune.
