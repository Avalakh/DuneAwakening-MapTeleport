# Map Teleport для Dune: Awakening

Мод для WPS Dune Launcher: перенос к обычной личной метке на большой карте Hagga Basin по **левому Shift + F12**.

Текущая версия — **0.1.3**. Поддерживается локальная одиночная игра. Переход между отдельными картами выполняется обычными игровыми средствами.

## Использование

1. Откройте карту M и поставьте обычную личную метку.
2. Нажмите левый Shift + F12.
3. Дождитесь сообщения «Перенос завершён», затем двигайтесь.

F12 без Shift не запускает перенос. Правый Shift может включать игровой автобег, поэтому рекомендуется левый. В транспорте перенос отклоняется. Мод не создаёт и не удаляет личные метки.

Территория подготавливается до переноса, точка проверяется по коллизии и размеру капсулы персонажа. Зазор под ногами — 0,5 м. После освобождения временных уровней дополнительно проверяются обычная опора и здоровье; при отказе выполняется контролируемый возврат.

## Установка и сборка

Проверенная среда: Dune: Awakening 1.5.3.0, WPS 1.2.13, UE4SS 3.0.1-1140-gf58e8f84. Совместимость с другими версиями не подтверждена.

Из корня проекта в PowerShell:

```powershell
./tools/package-mod.ps1
```

Импортируйте полученный `dist/MapTeleport-0.1.3.zip` через WPS и включите Map Teleport. Диагностический MapTeleportProbe должен быть выключен. Сборка содержит только семь собственных файлов мода; Runtime, файлы игры и чужие моды не распространяются.

Подробнее: [README мода](mods/MapTeleport/README.md), [совместимость](docs/compatibility.md).

## Проверки

Для автоматических тестов нужен Lua 5.4 в PATH:

```powershell
lua tests/teleport_test.lua
lua tests/map_adapter_test.lua
lua tests/runtime_test.lua
lua tests/main_test.lua
```

Пройдена 51 автоматическая проверка. В игре проверены повторные переносы, ходьба после завершения без возврата, дальняя область, тайм-аут и отказ на реальном байке. Межкартовый переход пока ожидает игровой проверки после получения орнитоптера. Полная приёмка остаётся `PENDING_USER_PLAYTEST`; [отчёт](docs/playtest-2026-10-23.md) различает проверки рабочего пакета и диагностического стенда. Локальные журналы, дампы и сохранения в репозиторий не включены.

## Разработка

Исходники рабочего мода находятся в `mods/MapTeleport/Scripts/`, тесты — в `tests/`. Каталог `native/` и `Scripts/native.lua` содержат ранний экспериментальный прототип: он не используется рабочим модом и не входит в ZIP.

OpenSpec установлен как локальная зависимость точной версии:

```powershell
npm ci
npx --no-install openspec validate add-map-click-teleport --strict
```

Изменение OpenSpec `add-map-click-teleport` остаётся открытым до оставшихся игровых проверок.
