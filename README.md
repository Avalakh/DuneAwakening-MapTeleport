# Map Teleport для Dune: Awakening

Мод WPS с полноэкранным выбором доступного региона и места появления. **Левый Shift + F12** открывает окно без перемещения персонажа.

Версия **0.3.0 установлена**; 23 файла совпали с воспроизводимым ZIP и прошли чистый запуск в wbox-mcp. Она добавляет штатные параметры изображения и обозначения мест, баз, заданий, личных меток и игрока. Результаты wbox-mcp и ограничения источников — [проверка карты](docs/map-presentation-playtest-2026-10-31.md), [устройство слоя](docs/map-presentation.md).

27.10 установлен кандидат исправления **0.2.1**: убран проблемный native TArray:ForEach из подготовки поверхности в UE4SS f58. Все 14 Lua-наборов PASS, 20 файлов ZIP совпали с установленными. Повтор вылета в игре остаётся PENDING_USER_PLAYTEST; это ещё не подтверждение устранения всех падений. [Разбор вылетов](docs/crash-2026-10-27.md).

Версия **0.2.0 установлена и принята пользователем 26.10.2026** после ручной проверки: «понажимал работает — принято». WPS распознал пакет и запустил без Probe. Проверены мышь, колесо, перетаскивание, клавиатурная навигация и физические переносы четырёх профилей карт. Непроверенные направления остаются PENDING_USER_PLAYTEST; приёмка не означает проверки каждого направления и каждой поверхности. Резервная копия прежнего 0.1.3 сохранена. Результаты и точные границы проверок — [отчёт 26 октября](docs/playtest-2026-10-26.md).

## Управление новым окном

1. Нажмите левый Shift + F12 и выберите доступный регион слева. Его местная карта сразу появится справа.
2. Если карта есть, на ней уже отмечено штатное место прибытия. Колесо меняет масштаб, зажатая ЛКМ или полосы прокрутки перемещают карту, «Вписать» показывает её целиком; полотно подстраивается под окно. Оставьте его или переставьте точку кликом. Нажмите **«Телепортироваться»** один раз. Для текущего региона выполняется местный перенос; для другого — путешествие и затем автоматическое размещение.
3. Если местной карты нет, эта же кнопка сразу отправляет к обычному месту прибытия региона.

Рядом **«Отменить»**, Escape также закрывает весь выбор без движения. Выбор региона и точки не перемещает персонажа. После принятого подтверждения штатное путешествие уже не отменяется кнопкой закрытого окна.

Личная метка и POI игры не используются как назначение и не меняются. F12 без Shift, Ctrl+F12 и Ctrl+Shift+F12 не запускают функцию мода. Удержание даёт одно открытие до отпускания F12. Правый Shift может включать игровой автобег, поэтому рекомендуется левый.

Требуется одиночная игра и живой персонаж вне транспорта. Доступность читается из штатных данных; окончательные условия путешествия проверяет игра. Мод не меняет прогресс и не разблокирует закрытые регионы. Неизвестная или не загрузившаяся карта не превращается в прямое путешествие.

## Безопасность размещения

Сначала проверяется точное выбранное место. Если оно непригодно, ищется безопасное место рядом с постепенным расширением поиска по карте; при отсутствии такого места перенос отменяется. Поверхность готовится до движения, проверяются уклон, блокирующая коллизия и свободный объём капсулы; зазор под ногами 0,5 м. Местная подготовка ограничена 15 секундами. После размещения и освобождения временной геометрии повторно проверяются опора и здоровье. При отказе выполняется контролируемое восстановление в том же мире.

Путешествие ограничено 120 секундами; прибытие проверяется минимум 3 секунды. Если новый регион достигнут, а размещение в точке не удалось, сообщение указывает частичный результат; восстановление относится к штатному месту прибытия нового региона. Координаты прежнего мира не применяются в новом.

## Сборка и проверка

```powershell
./tools/package-mod.ps1
```

Сборка 0.3.0 создаёт отдельный `dist/MapTeleport-0.3.0.zip` и SHA-256; прежние ZIP сохраняются. Пакет содержит 23 собственных файла, без Runtime, чужих модов, Probe и сохранений. Импорт через WPS проверяется отдельно; до завершения игровой приёмки пакет является кандидатом.

Фактическая среда новой проверки: Dune: Awakening 1.5.3.0, WPS 2.1.1, UE4SS 3.0.1-1140-gf58e8f84. Другие версии не квалифицированы.

Тесты Lua 5.4:

```powershell
Get-ChildItem tests/*_test.lua | ForEach-Object { lua $_.FullName; if ($LASTEXITCODE) { throw "Test failed" } }
```

Матрица регионов — [region-catalog](docs/region-catalog.md), проверенные API и ограничения — [region-game-api](docs/region-game-api.md), [откат](docs/rollback.md), [совместимость](docs/compatibility.md). Старый [отчёт 0.1.3](docs/playtest-2026-10-23.md) не доказывает работоспособность нового окна и цепочки путешествия.

## Разработка

Исходники: `mods/MapTeleport/Scripts/`; тесты: `tests/`. Ранний эксперимент `native/` и `Scripts/native.lua` не используется и не входит в ZIP.

```powershell
npm ci
npx --no-install openspec validate add-region-travel-and-map-support --strict
```

Активное изменение `add-region-travel-and-map-support` остаётся открытым до выполнения задач. Историческое `add-map-click-teleport` не закрывается и не синхронизируется автоматически.
