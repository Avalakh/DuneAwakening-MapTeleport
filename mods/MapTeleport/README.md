# Map Teleport 0.2.0 — тестовый пакет

Мод для WPS Dune Launcher. Одиночная игра, живой персонаж вне транспорта.

## Управление

1. Левый Shift + F12 открывает полноэкранное окно без перемещения.
2. Выберите доступный регион слева. Его карта сразу появится справа.
3. Если есть местная карта, оставьте штатную точку прибытия либо измените её кликом. Колесо над картой меняет масштаб относительно указателя; карту можно тянуть зажатой ЛКМ либо перемещать полосами прокрутки. Кнопка «Вписать» показывает карту целиком. Полотно подстраивается под размер окна.
4. Один раз нажмите «Телепортироваться». Для текущего региона выполняется местный перенос. Для другого — штатное путешествие и автоматическое размещение после прибытия. Без местной карты выполняется только штатное путешествие к обычному месту появления.

«Отменить» и Escape закрывают выбор без перемещения. После окончательного подтверждения принятое игрой путешествие уже выполняется. F12 без Shift, Ctrl+F12 и Ctrl+Shift+F12 не запускают мод. Правый Shift может включать игровой автобег; используйте левый.

Tab и Shift+Tab переводят фокус между доступными кнопками, Enter нажимает выбранную. Пока окно открыто, ввод направлен только в него; при закрытии управление возвращается игре.

Личные метки и POI игры не являются назначением и не меняются. Закрытые прогрессом направления не разблокируются. Игра проверяет окончательные требования маршрута; unknown/ошибка карты не означает отсутствие карты и не разрешает прямое путешествие.

## Размещение

Сначала проверяется выбранный X/Y. При препятствии поиск расширяется от него в пределах карты; опора, уклон, полная капсула и зазор над поверхностью обязательны. Подготовка ограничена 15 секундами. При отказе после путешествия персонаж остаётся либо восстанавливается на проверенном месте в новом регионе. Координатного возврата в прежний мир нет.

## Установка и откат

Импортируйте ZIP через «Add mod» в WPS и включите Map Teleport. Закройте игру перед заменой пакета. Для отключения снимите флажок мода перед следующим запуском. Для отката импортируйте сохранённый MapTeleport-0.1.3.zip; он возвращает прежнее управление через личную метку только в Hagga Basin.

Пакет содержит только собственные Lua-файлы и manifest. Probe, Runtime, сторонние моды и сохранения не включены.

## Статус проверки

Это кандидат 0.2.0, игровая приёмка ещё не завершена. Среда проверки: Dune: Awakening 1.5.3.0, WPS 2.1.1, UE4SS 3.0.1-1140-gf58e8f84. Другие версии не квалифицированы. Покрытие DeepDesert, точность всех ориентиров и полный набор многоуровневых мест ещё не подтверждены. Исходники и подробные отчёты: https://github.com/Avalakh/DuneAwakening-MapTeleport (локальные изменения могут быть ещё не опубликованы).
