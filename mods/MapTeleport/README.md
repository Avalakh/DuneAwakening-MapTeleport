# Map Teleport 0.1.3

Мод WPS для переноса к обычной личной метке в одиночной Hagga Basin.

Откройте карту M, поставьте личную метку обычным ПКМ и нажмите **левый Shift + F12**. Карту можно закрыть перед нажатием. Правый Shift в текущих настройках игры включает автобег; пользователь оставил эту привязку. Мод не меняет игровые назначения клавиш.

При подготовке и проверке переноса управление персонажем временно блокируется и возвращается после завершения операции. Новый запрос во время операции отклоняется. При отсутствии метки, в транспорте, в сетевой сессии и на неподдерживаемой карте перенос не выполняется. Обычные действия карты и постановка метки не переназначаются.

Точка подготавливается до перемещения персонажа: загружаются полный ландшафт, Art и ArtCollision выбранных участков. Из верхней поверхности и реальной высоты капсулы вычисляется центр персонажа с зазором под ногами 0.5 м (допустимый диапазон 0.3–1.0 м). Склон и занятое место отклоняются. Двумерная метка не выбирает этаж подземелья. Между отдельными картами/серверами используйте обычные игровые переходы.

После переноса мод проверяет положение и здоровье не менее трёх секунд, затем проверяет обычные столкновения после освобождения временных уровней. При отказе возвращает персонажа в подготовленную исходную точку. Природные опасности и враги остаются игровыми опасностями.

Проверенная среда: игра 1.5.3.0, WPS 1.2.13, UE4SS 3.0.1-1140-gf58e8f84. Новой зависимости от Framework нет. Диагностический файловый мост, Runtime и нативный прототип в пакет не входят.

Пакет содержит mod.json, этот README и Scripts/: main.lua подключает ввод, runtime.lua фильтрует удержание, teleport.lua управляет этапами запроса, map_adapter.lua обращается к игре, geometry.lua проверяет координаты и геометрию.

## Build

Из корня проекта:

```powershell
./tools/package-mod.ps1
```

Архив и SHA-256 находятся в dist/. Скрипт включает только собственные файлы по явному списку и проверяет структуру архива.

## Install

Закройте тестовую игру. Импортируйте dist/MapTeleport-0.1.3.zip в WPS, включите Map Teleport и выключите временный MapTeleportProbe. Запустите игру через WPS. Удаление: выключите Map Teleport перед следующим запуском и удалите только этот пакет через WPS. Сохранения и остальные моды удалять не требуется.

## Validation

Статус сборки: **PENDING_USER_PLAYTEST** до завершения всей игровой матрицы. Подробные результаты, ограничения и ещё не пройденные сценарии указаны в docs/game-api.md и docs/compatibility.md проекта. Прохождение автоматических тестов не означает завершения игровой приёмки.

В 0.1.1 обработка запросов перенесена в один постоянный таймер игрового потока. Обработчик клавиши только отмечает нажатие и не создаёт отложенных callbacks; исправляется остановка после сообщения подготовки с ошибкой UE4SS `Ref was not function` в 0.1.0.

В 0.1.2 исправлено ограничение движения во время проверки переноса: используется собственный Enhanced Input Component в стеке ввода, освобождаемый вместе с запросом. Перед передачей персонажа обычному стримингу проверяется уровень фактической опоры; посторонние пересекающиеся границы кораблей и пещер больше не вызывают ложное ожидание. Зазор над поверхностью остаётся 0.5 м.

В 0.1.3 проверка транспорта получает настоящего персонажа через GetDunePlayerCharacter: за рулём контроллер управляет транспортом, который не имеет интерфейса здоровья персонажа. Отказ на байке подтверждён в игре без перемещения и подготовки точки. Проверка обычного межкартового перехода отложена пользователем до появления орнитоптера.
