# Design

## Context

map_view_adapter создаёт копии native CartographyMapLayerActor на previewZ=10000000 и собственный SceneCapture/RT. Он вручную устанавливает CaptureSource=10, AutoExposureMethod=0 и AutoExposureBias=1. Штатные PostProcess/материалы отображения не копируются; источник различия изображения ещё надо подтвердить чтением native capture и экранным сравнением. Наш Image показывает RT без слоя обозначений. Стандартные данные обнаружены reflection: PlayerMapMarkerComponent.m_MapMarkers, DuneGlobalDataCacheSubsystem.PerMapData.Global.StaticMarkers, FullscreenMapMarkerRowBase с m_IconTexture/m_MarkerDisplayName и MapMarkerWidgetBase.

Основных синхронизированных спецификаций нет; прошлый active change сохраняет поведение выбора/путешествия. 0.2.1 с исправлением TArray имеет отдельный незавершённый игровой статус. Резервная копия текущих 60 файлов и ZIP: work/backups/before-native-map-20261031-160858/source-and-package.zip, SHA-256 44DCDD71E5AF6F3C12312BBD76A49007F035F336637234E75CABCFDDF0D2588C, восстановление проверено.

## Goals / Non-Goals

**Goals:** штатный вид либо максимально близкое собственное представление; места/базы/задания/личные метки; подписи, подсказки и игрок; корректный zoom/pan/DPI; просмотр другого региона без travel; безопасное владение UI.

**Non-Goals:** изменение физического переноса и прогресса заданий, исправление сторонних native ошибок маркеров, публикация на GitHub без отдельного запроса, раскрытие закрытых мест и решение прежних неподтверждённых вылетов под видом изменения карты.

## Decisions

1. Сначала проверить штатный W_FullscreenMap/Cartography display и native capture/RT/UI brush. Переиспользовать штатный виджет, если его можно изолировать от PlayerMenu и показывать другую карту без изменения живой native карты. Иначе сохранять собственный контекст preview и брать параметры изображения из native источников, не подбирать произвольный контраст на глаз.
2. Адаптер обозначений формирует plain snapshots с mapId/layer/XY/type/name/icon/visibility. UObject и изменяемые native structs не кешируются между callback/сменой мира. Текущие динамические данные и региональный static cache отделены; непрочитанные remote данные обозначаются явно и не заменяются текущими.
3. Проекция всех overlay совпадает с map_projection/map_canvas. Значки ограничены viewport, остаются постоянного читаемого размера; tooltip и подписи не меняют игровой PersonalMarker. Обновление слоя не вызывает present и не теряет wheel queue/scroll offsets.
4. Чтение TArray через unreal_array с проверкой размера; не возвращать ForEach и массовый поиск тысяч wrapper. Штатные данные и стили читаются; меняются только собственные UMG/RT/actor instances.
5. Фильтры и признаки исследования берутся из доступного штатного состояния. Полный native каталог не означает право показать все скрытые POI. До выбора конкретного фильтра проверить структуру discovery и идентичность marker IDs.

## Risks / Trade-offs

- Native widget может предполагать активное PlayerMenu/текущий мир: проверить это отдельно; не переподчинять чужой виджет и не ломать навигацию штатного меню.
- Remote динамические данные могут отсутствовать: нужна явная индикация и проверенный источник, а не подставные метки.
- Копирование целых структур UE4SS ранее приводило к aliasing: переносить проверенные поля либо использовать собственный экземпляр штатного класса, не присваивать wrapper самому себе.
- Различия HDR/gamma/postprocess/освещения пока гипотезы. Требуется native readback и визуальная проверка текущей и чужой карты. Сравнение FPS и пиксельные метрики пользователь не требует.
- Существующий пользовательский сеанс сохраняется; перед диагностическим перезапуском сохранить снимок Cloud. Временные процессы записывать по PID/creation/executable и закрывать после опыта; рабочий выбор MapTeleport enabled/Probe disabled восстановить обязательно.

## Implementation findings — 2026-10-31

Native RT format/gamma, CaptureSource=10, FoV=100 и exposure сами по себе не объясняли бледность. Контроль показал контрастный native raw RT в нашем Image и восстановление склонов при штатной высоте своей камеры. Реализация сохраняет native FoV, изменяет высоту с zoom и переносит десять scalar postprocess полей с override-флагами. Размер RT ограничен считанными m_MaxMapRTSize; произвольного цветового фильтра нет.

Выбран изолированный preview: W_FullscreenMap связан с PlayerMenu и текущим CartographyMapSubsystem, отражённого setter удалённого региона нет; отдельно созданный native marker overlay имел 0 marker widgets. Для значков переиспользуются реальные W_DuneIconPreset с native icon/preset. SPS marker map и indexed dynamic cache дают авторизованные данные текущего мира, полный static catalog не показывается. Для другого региона данные явно недоступны, пока нет источника. Полный пользовательский native filter menu не воссоздаётся.

GUI-проверки после требования пользователя выполняются только через wbox-mcp в Windows Sandbox, на копии сохранения. Sandbox-only fixture для открытия окна нужен из-за одновременных down/up синтетического сочетания; он не входит в пакет. Физическая проверка Shift+F12 и реальный значок задания отдельно от pure-тестов остаются открытыми до подтверждения.
