# Proposal

## Why

MapTeleport 0.1.3 ограничен переносом к личной метке Hagga Basin. Игроку нужен единый интерфейс: выбрать доступный регион, при наличии его карты указать точку и только после окончательного подтверждения начать путешествие и безопасное размещение.

## What Changes

- Окно полноэкранное, с максимальным переиспользованием штатных компонентов и сходством со стандартными окнами игры. Отдельные замеры производительности пользователь исключил из работ.

- **BREAKING**: Shift+F12 открывает собственное окно телепортации вместо немедленного переноса к игровой метке. Отдельная команда Ctrl+Shift+F12 для регионов из прежней редакции плана отменяется.
- Shift+F12 открывает единый экран: список доступных регионов слева, сразу местная карта выбранного региона справа. Текущий регион выбран по умолчанию. Дополнительного открытия региона и второго подтверждения нет.
- На карте по умолчанию отмечено штатное место прибытия из игровых данных маршрута. Игрок оставляет его либо выбирает другую точку и один раз нажимает «Телепортироваться». Без местной карты эта кнопка запускает штатное путешествие к обычному месту прибытия. Рядом «Отменить», Escape также отменяет весь выбор без движения.
- Сначала проверяется выбранная точка; если она непригодна для персонажа, ищется безопасная опора с расширением поиска по границам карты с теми же проверками капсулы и уклона. При отсутствии подходящего места перенос отменяется.
- Для текущего региона с картой выполняется только местное размещение. Для другого региона с картой одна операция последовательно выполняет штатное путешествие, проверку прибытия и перенос к заранее выбранной точке. Повторное нажатие сочетания или постановка личной метки после прибытия не нужны.
- Переиспользуются штатные данные/ресурсы обзорной и местных карт, если проверена возможность их отображения в собственном окне. Поддержка предварительного просмотра незагруженного региона является обязательной проверкой, а не предположением.
- Только доступные персонажу регионы; сюжетные флаги, сохранения и чужие моды не меняются. Безопасность опоры, одиночный режим, живой персонаж вне транспорта, ограниченная подготовка и очистка сохраняются.
- Архив-бэкап решения 0.1.3 и прежних артефактов создан до правок; перед будущей реализацией и установкой проверяется возможность отката.
- Не входят сетевые серверные переходы, разблокировка прогресса, угадывание подземного этажа по двумерной карте и привязка нового интерфейса к личным меткам игры.

## Capabilities

### New Capabilities

- `region-travel`: единый вход Shift+F12, выбор доступного региона на обзорной карте, ветвление по наличию местной карты, штатное путешествие и управление составной операцией.
- `map-teleport`: предварительный выбор собственной точки на местной карте выбранного региона и безопасное размещение в актуальном мире назначения. Путь сохранён из предыдущего изменения; основной спецификации пока нет.

### Modified Capabilities

Основных спецификаций пока нет. Это уточнение интерфейса и последовательности того же `add-region-travel-and-map-support`, а не новый параллельный механизм. Предыдущий незавершённый `add-map-click-teleport` описывает историческое поведение 0.1.3; при будущей синхронизации его старый контракт метки и мгновенного Shift+F12 не должен перезаписать этот новый контракт. Старые незавершённые проверки не закрываются автоматически.

## Impact

Ввод и координатор `main.lua`/`runtime.lua`, источник назначения и профиль карты в `map_adapter.lua`, безопасный автомат `teleport.lua`; собственные модули окна, каталога, карт и межкартового путешествия. Изменятся тесты, manifest, явный список упаковки и пользовательская документация. Существующие доказательства 0.1.3 не подтверждают предварительное отображение карт или межрегиональные переходы. На этапе update меняются только пять существующих файлов плана; реализация и установленный мод сохраняются.
